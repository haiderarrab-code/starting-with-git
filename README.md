# نظام البحث الموحّد في قواعد البيانات

برنامج سطح مكتب (Windows) للبحث الموحّد عبر ملفات **Excel** و **SQLite**.
سريع جداً حتى مع مئات آلاف السجلات بفضل العرض الافتراضي (Virtual Scrolling)
ومعالجة الملفات في خيط منفصل (Web Worker). يعمل بالكامل **بدون إنترنت**.

## المزايا
- استيراد ملفات Excel (`.xlsx` / `.xls` / `.csv`) و SQLite (`.db` / `.sqlite`)
- **استيراد مجلد كامل** بضغطة واحدة — كل ملفات Excel داخله تُسحب تلقائياً
- بحث موحّد فوري عبر كل المصادر مع تظليل النتائج
- **تصدير موحّد**: دمج كل البيانات في ملف Excel واحد بشيتات مسمّاة
- حفظ تلقائي، وضع ليلي/نهاري، واجهة عربية RTL

## التشغيل السريع (للتجربة)
```bash
npm install
npm start
```

## بناء ملف التثبيت (.exe)
على ويندوز، نفّذ مرة واحدة:
```bash
npm install
npm run dist
```
سينتج المثبّت داخل مجلد `dist/`:
- `UnifiedDBSearch Setup x.x.x.exe` — مثبّت عادي (ينشئ اختصاراً على سطح المكتب)
- نسخة **portable** تعمل بنقرة مزدوجة بدون تثبيت

بعدها شغّل البرنامج من أيقونته مباشرةً — لا حاجة لـ terminal أو npm.

## البنية
| الملف | الوظيفة |
|------|---------|
| `electron-main.js` | عملية Electron الرئيسية — تشغّل خادماً داخلياً وتفتح النافذة |
| `index.html` / `style.css` | الواجهة |
| `app.js` | منطق الاستيراد والبحث والعرض الافتراضي |
| `xlsx-worker.js` | معالجة Excel في خيط منفصل |
| `vendor/` | المكتبات المحلية (xlsx + sql.js) للعمل بدون إنترنت |
